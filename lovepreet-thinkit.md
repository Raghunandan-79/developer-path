## 📚 Phase-by-Phase Details

### Phase 1: Core Java & Low-Level Foundations (Weeks 1–10)

*Goal: Master Java syntax, OOP, concurrency, memory models, and core libraries.*

* **Weeks 1–2:** Setup (WSL, Maven, IDE), System Streams, Print & Basic Syntax.
* **Weeks 3–4:** Classes, Objects, Modifiers, Wrapper Classes, Primitives, Bits/Bytes, Loops, Functions, Recursion.
* **Week 5:** JVM Internals (Heap, Stack, Compilers, Threading model).
* **Week 6:** Serializables, Iterables, Interfaces, Marker Interfaces.
* **Week 7:** File IO, Advanced Concurrency & Threading (with mini projects).
* **Week 8:** Functional Java (Streams API, Optionals, Map/Filter, Generics, Collection Framework).
* **Week 9:** Socket Programming, Networking, JavaFX & Async Programming.
* **Week 10:** Java Plain HTTP Library & **Live Project: Building a Logging System (Part 1 & 2)**.

---

### Phase 2: Data Structures & Algorithms — DSA (Weeks 11–23)

*Goal: Build algorithmic problem-solving skills for technical interviews.*

* **Weeks 11–15:** Basic Math, Hashing, Strings, Array Basics, Kadane’s Algorithm, Moore Voting & Inversion Patterns.
* **Week 16:** ⏸️ *Mid-way Break (Rakshabandhan / Catch-up week)*
* **Weeks 17–19:** Binary Search, Recursion, Backtracking, Linked Lists, Greedy Algorithms.
* **Weeks 20–21:** Stacks, Queues, Sliding Window, Heaps & Priority Queues, Binary Trees & BSTs.
* **Weeks 22–23:** Graphs (I & II), Dynamic Programming, plus **Live Project: Async Image Processing**.

---

### Phase 3: Object-Oriented Design & Design Patterns — LLD (Weeks 24–31)

*Goal: Learn clean code, SOLID principles, and software architecture patterns.*

* **Week 24:** SOLID Principles, Strategy & Observer Patterns (*Project: File Manager*).
* **Week 25:** Decorator Pattern.
* **Week 26:** Factory & Abstract Factory Patterns (*Project: Mini Game Engine Framework*).
* **Week 27:** Low-Level Design Case Studies (Parking Lot, Game Engine).
* **Weeks 28–29:** Chain of Responsibility, Proxy & Null Object Patterns (*Projects: Toksmith & Flatmate*).
* **Week 30:** State, Composite, Adapter, Builder, and Bridge Patterns.
* **Week 31:** Command, Iterator, and Visitor Patterns.
* **Key Capstone:** Group Project — *Stock Exchange Simulation v1.0*.

---

### Phase 4: Enterprise Web Development with Spring Boot (Weeks 32–43)

*Goal: Learn production-ready backend development, security, caching, and monitoring.*

* **Weeks 32–35:** Spring Overview, Dependency Injection (DI), Bean Scopes, Lifecycles, Profiles.
* **Weeks 36–37:** Aspect-Oriented Programming (AOP), Spring JDBC, `@Transactional` management (*LLD Project: Snake & Ladder*).
* **Weeks 38–39:** Web Server setup, REST APIs, Spring Security (Authentication & Authorization).
* **Weeks 40–41:** High Performance & Caching (Caffeine, Redis), Pagination, Batching.
* **Week 42:** Async Processing, WebSockets, Server-Sent Events (SSE), and Observability (Actuator, Logging, Metrics, Tracing).
* **Week 43:** Industry Trends & Preparation.

---

### Phase 5: Spring AI & Modern AI Integration (Weeks 44–45)

*Goal: Build modern AI-enabled applications using Java and Spring Boot.*

* **Week 44:** LLM Architecture, Embeddings, Vector Databases, Retrieval-Augmented Generation (RAG) Basics.
* **Week 45:** Integrating LLM APIs into Spring Boot applications.

---

### Phase 6: Career Prep & Group Projects (Integrated Throughout)

* **Live Capstone Projects:** Logging System, Async Image Processor, Stock Exchange Simulator, Flatmate App, Toksmith.
* **Career Weeks (Weeks 34 & 43):** Interview experiences, mock prep, and navigating the IT job market.
